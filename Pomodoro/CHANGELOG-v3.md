# Pomodoro Liquid Glass — v3

- Мобільний таймер став горизонтальним та компактним: ліворуч відлік, праворуч невеликий помідор із відсотком виконання.
- Поле «Назва процесу або задачі» перенесено до блоку таймера.
- Блок кнопок перейменовано на «Старт сесії» та поставлено одразу після таймера на мобільних екранах.
- Порядок на мобільному: таймер → керування → інтервали → нотатки.
- Збережено ті самі ID елементів та логіку роботи таймера, звітності й локальних даних.

# Pomodoro Liquid Glass

Легкий автономний Pomodoro SPA українською мовою. HTML + CSS + ES modules, без фреймворків, збірки, CDN, зовнішніх шрифтів, бекенду та аналітики.

## Запуск локально

Через ES modules сторінку краще запускати через локальний HTTP-сервер, а не `file://`.

```bash
python3 -m http.server 8000
```

Відкрийте http://localhost:8000

## Деплой на GitHub Pages

1. Розпакуйте архів у корінь репозиторію.
2. Переконайтеся, що `index.html` лежить у корені гілки `main`.
3. У GitHub відкрийте **Settings → Pages**.
4. У **Build and deployment** виберіть **Deploy from a branch**, гілку `main`, папку `/ (root)`.
5. Збережіть. Усі шляхи відносні, тому сайт працює і з адреси `username.github.io/repo/`.

Також можна завантажити файли у репозиторій через Git:

```bash
git add .
git commit -m "Add Pomodoro Liquid Glass"
git push origin main
```

## Можливості

- Пресети 25/5, 50/10, 90/15 та власна тривалість.
- Робочий/переривний інтервали, пауза, продовження, стоп і скидання.
- Відлік на основі абсолютного timestamp — не залежить від частоти таймера браузера.
- Відновлення після перезавантаження; синхронізація вкладок через `storage`.
- Сигнал Web Audio та браузерні сповіщення за дозволом.
- Опціональний Screen Wake Lock (підтримка залежить від браузера).
- Назва процесу, нотатки, редагування, видалення, копіювання, дата з автоінкрементом.
- Історія завершених/зупинених сесій за поточний день.
- Користувацький фон: стиснення через canvas і збереження Blob в IndexedDB.

## Дані та приватність

Налаштування, таймер, нотатки та історія зберігаються у `localStorage`. Користувацький фон — у `IndexedDB`. Дані не відправляються на сервер і не залишають пристрій. Очищення даних сайту в браузері видалить локальні записи.

## Шрифти Ermilov

Файли `Ermilov-Bold.woff2` та/або `Ermilov-Bold.otf` можна додати в `/fonts`. Переконайтеся, що ліцензія дозволяє веб-вбудовування, а файли містять потрібні кириличні гліфи. Якщо файлів немає, автоматично використовується системний шрифт.

## Контакти у футері

Відредагуйте два текстові елементи в `index.html` у `<footer>`: додайте ім'я, email, Telegram або GitHub.

## Обмеження браузерів

- Таймер рахує за абсолютним часом, тому згортання вкладки й сон пристрою не збивають залишок. Після повернення інтерфейс перераховує його.
- Фонове відтворення звуку та показ сповіщень, коли вкладка закрита або браузер зупинений, не гарантуються.
- На iOS системні сповіщення для вебзастосунків доступні з обмеженнями; надійніший сценарій — встановити сайт на екран «Додому» як PWA (iOS 16.4+). Цей реліз не включає PWA manifest/service worker.
- Звук запускається після взаємодії користувача з кнопкою «Пуск».
- Screen Wake Lock доступний не в усіх браузерах і зазвичай потребує HTTPS.

## Примітки до реалізації

Версія 1.0 без етапу збірки. Рядки інтерфейсу наразі зібрані в українській розмітці та модулях; для наступної локалізації їх варто винести в окремий словник. Рекомендується перевірити поведінку на цільових версіях Safari iOS/macOS, Chrome, Firefox та Edge перед публічним релізом.
